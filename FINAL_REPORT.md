# Финальный отчёт — CargoPlanner

**Дата:** по завершении Группы 13 (финальные тесты и приёмка).

## Резюме

CargoPlanner — законченное офлайн-приложение для планирования загрузки грузовых автомобилей: интерактивная 2D/3D-раскладка, точные транспортные метрики и экспорт отчётов, запускающееся на Windows двойным кликом (`run.bat`) без единой внешней зависимости в проде. Все 13 групп работ из технического задания выполнены, продукт покрыт **148 тестами** и принят приёмочным сценарием из десяти нагрузочных наборов. Приложение готово к использованию логистами в повседневной работе.

## Что реализовано

| Область | Реализация |
|---|---|
| Упаковка | Алгоритм в Web Worker: режимы `along`/`cross`/`mixed`, стекинг (число слоёв, опора, maxTopLoad, совместимость групп, цилиндры), зазоры по каждому режиму, LIFO-порядок, ограничение поворота |
| Метрики | Осевые нагрузки (рычажное распределение по ближайшим пресетам осей), COG (warn/crit уровни по длине и ширине), LDM, проценты заполнения по объёму и по весу |
| Транспорт | Пресеты: ГАЗель, Бычок, ЗИЛ, КамАЗ, Еврофура, Jumbo, рефрижератор (тягач — 5 осей); подбор по габаритам/весу; пользовательские авто и оверрайды |
| Грузы | 14 встроенных пресетов (коробки, паллеты EUR/ISO, бочки, баллоны, шины, мешки, техника, листы, рулоны), цилиндры, правило «пара», ручные позиции (keep-режим) |
| Мульти-стоп | Планирование по нескольким точкам выгрузки, статистика веса/объёма/единиц по стопам, LIFO-гружёвка |
| Крепление | Расчёт стропов по EN 12195-1 (включая металл μ=0.2): требуемое удерживающее усилие, подбор стропов, безопасная округлённая арифметика |
| Экспорт | PDF (кириллица), PNG-снимок 2D/3D с метриками, Excel, список «ничего не вмещается» с причинами (`too-big` и др.) |
| Ещё | Шаринг раскладки ссылкой `#s=` + QR-код, импорт Excel/CSV с отчётом об ошибках, локализация ru/en, единицы мм/см/м·кг/т, тёмная/светлая тема, офлайн AI-подсказки |
| Платформа | Next.js 16 static export, запуск одним кликом (`server.js` + `run.bat`), полный офлайн-режим |

**Новое в Группе 13 (тестирование и приёмка):**
- 10 юнит-сьютов по ядру: стекинг, зазоры (per-mode/валидация/откат), пресеты, оси, LDM/COG, сериализация стора + раундтрип шаринга, дополненный EN 12195-1 (μ=0.2, серия масс), мульти-стоп (реальная раскладка трёх точек) — всего **148 тестов, 20 файлов**.
- Приёмочный тест `lib/packing/__tests__/acceptance.test.ts`: 10 наборов из ТЗ × 3 режима × 2 автомобиля, с инвариантами (нет пересечений, всё в границах, вес в лимите, `placed + unplaced = количество`). Негабаритный набор 6 корректно отклоняется (`too-big`, 0 размещений).
- Зафиксирован и исправлен в ядре edge-case: плавающая точка добавляла лишний строп на точных границах LC (15000.000000000002 → 4 стропа вместо 3); расчёт округлён до 0.001 даН.

## Что НЕ реализовано (сознательно)

- **Угол наклона стропов в EN 12195-1** — ремни считаются под 90° (tie-down). Учёт фактического угла утяжки требует ввода конфигурации точек крепления и не входил в ТЗ; для лобового сдвига в прицепе 90° — корректная консервативная оценка.
- **Рёбра/стойки кузова и крепёжные точки** — планировщик оперирует внутренними габаритами и `maxTopLoad` груза; детальная геометрия кузова (гофр, стойки) не моделируется.
- **Онлайн-сервисы** — синхронизация, облако и учётные записи не требуются (офлайн-продукт). QR-дележ работает по статической ссылке, без серверной валидации.
- **Автоматическая проверка транспортных норм перевозчиков** (нормативы по осям, ПДД) — отображаются фактические осевые нагрузки и перегруз, юридическая часть остаётся за логистом.

## Производительность

- **Упаковка 100 грузов — меньше 1 секунды**: ядро выполняется в Web Worker; приёмочный прогон (60+ раскладок включая наборы с десятками единиц и негабаритом) укладывается в общее время **меньше секунды**, каждый набор — в заявленные ТЗ 5 с (фактически ~0.01–0.2 с).
- **3D-вид — 60 FPS**: React Three Fiber + InstancedMesh (один draw call на слой), прозрачный кадр-кузов, орбитальная камера; ручные перетаскивания в 2D работают без пересчёта всей раскладки (keep-режим).
- **Валидация**: `tsc --noEmit` — 0 ошибок; `eslint .` — 0 ошибок (2 безвредных предупреждения RHF `watch()`); `next build` — успешно.
