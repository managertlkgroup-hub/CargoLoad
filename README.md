# CargoPlanner

Премиальный планировщик загрузки грузовых автомобилей: 2D/3D-раскладка в реальном времени, метрики (оси, COG, LDM), подбор техники и экспорт отчётов. Работает полностью офлайн, запускается двойным кликом на Windows.

## Скриншоты

Скриншоты появятся позже. Приложение можно посмотреть вживую: запустите `run.bat` (Windows) или `npm run dev`.

## Возможности

**Базовые**
- Упаковка грузов колоннами/слоями в Web Worker (без блокировки интерфейса)
- 2D-вид с drag-and-drop и режимом keep (ручные позиции не пересчитываются)
- 3D-вид: прозрачный кузов, слои, орбитальная камера
- Подбор автомобиля, подсветка невмещающихся грузов, стекинг
- Тёмная/светлая тема, локализация ru/en, единицы мм/см/м и кг/т
- Импорт Excel/CSV с отчётом об ошибках

**Продвинутые**
- Мульти-стоп загрузка (LIFO: последний стоп грузится первым)
- Осевые нагрузки, COG-индикатор, LDM и коэффициенты использования
- Паллетизация (EUR/ISO/half) и расчёт числа машин
- Расчёт крепления груза по EN 12195-1 (число стропов)
- Типы загрузки (боковая/задняя) для дос-машин и холодильников
- Экспорт: PDF с кириллицей, PNG-снимок 2D/3D с метриками, Excel
- Шаринг раскладки ссылкой + QR-код, офлайн AI-подсказки

## Установка

```bash
npm install
```

## Запуск

- **Windows (одним кликом):** двойной клик по `run.bat` — сам установит зависимости, соберёт проект, откроет браузер и запустит локальный сервер. Работает без интернета.
- **Разработка:** `npm run dev`
- **Сборка:** `npm run build` (статический экспорт в папку `out/`)
- **Продакшн:** `node server.js` (чистый Node.js, без зависимостей) → http://localhost:3000

## Архитектура

- **Next.js 16 static export** (`output: "export"`) — вся сборка в статику `out/`
- **Алгоритм упаковки** — в Web Worker, колоночный/слоистый режимы, правила груза (поворот, слои, пара)
- **Zustand** — единые стора состояния (cargo, layout, session, ui) с персистентностью
- **React Three Fiber** — 3D-вид (InstancedMesh, кадр-кузов)
- **dnd-kit** — 2D drag-and-drop; **Tailwind v4 + shadcn/ui (Radix)** — интерфейс и темы
- **Экспорты:** react-pdf (PDF), xlsx/SheetJS (Excel), html2canvas (PNG)
- **Статический сервер** — `server.js` на встроенных модулях Node.js

## Результаты тестирования

Проект финально протестирован и принят. Полный прогон: `npm test` (vitest), `tsc --noEmit`, `eslint .`, `npm run build`.

- **148 тестов в 20 файлах** — ядро упаковки, геометрия и единицы, стекинг (слои, опора, maxTopLoad, группы, цилиндры), зазоры (per-mode, валидация, откат), пресеты, оси (рычажное распределение), LDM/COG, EN 12195-1 (формула, подбор стропов, μ=0.2), мульти-стоп, шаринг+сериализация, экспорты PNG/Excel
- **Приёмочный тест `lib/packing/__tests__/acceptance.test.ts`** — 10 нагрузочных наборов из ТЗ (паллеты, хрупкое, негабарит и т.д.) × 3 режима (`along`/`cross`/`mixed`) × 2 автомобиля (КамАЗ-4308 и Еврофура). Проверяет инварианты: никаких пересечений, всё в границах кузова и весового лимита, `placed + unplaced = количество`. Набор 6 (негабарит) обязан быть отклонён как `too-big`. Весь прогон — меньше секунды (лимит 5 с).
- Статусы: **tsc — 0 ошибок**, **eslint — 0 ошибок**, **build — успешно**, **vitest — 148/148 зелёных**.

## Известные ограничения

- Два безвредных предупреждения ESLint `react-hooks/incompatible-library`: RHF `watch()` в `cargo-dialog.tsx:184` и `vehicle-dialog.tsx:205` (компилятор пропускает мемоизацию — на стейл-UI не влияет, исправление потребовало бы рефакторинга форм).
- Планировщик не учитывает рёбра/стойки кузова и крепёжные точки в кузове; оценка прочности опоры — по `maxTopLoad` груза.
